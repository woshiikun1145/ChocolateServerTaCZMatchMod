# Chocolate Server Tacz Match Mod玩家手册

此模组是为 Chocolate Server的TaCZ子服设计的匹配、商店、投票模组。

> 本手册只介绍基本操作方法。服务器管理员/配置人员请参阅 [CONFIG.md](CONFIG.md)（配置手册），模组运行原理与网络协议请参阅 [DEVELOPER.md](DEVELOPER.md)（面向调试人员），网络相关请参阅 [NETWORK.md](NETWORK.md)（网络协议），其他模组/插件开发者请参阅 [API.md](API.md)（API 调用手册）。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `;` | 打开/关闭匹配菜单 |
| `'` | 打开/关闭商店 |
| `F7` | 投票：同意 |
| `F8` | 投票：不同意 |

> 进服提示"未与服务端握手成功"时所有快捷键不可用，请联系服务器管理员。

## 匹配菜单（默认 ; 键（L键右边））

- **欢迎页**：模组介绍与当前可用地图数量。
- **匹配页**：
  - 标题栏右侧选择 **休闲模式 / 竞技模式**（选中的带 `✔`），加入队列时按当前选中的模式入队。
  - 卡片列表：每张启用的地图一张卡片，首张为"⚡ 快速匹配"入口。
  - 点击卡片直接加入队列（快速匹配无队伍概念），红/蓝队伍由系统自动平衡分配（两队人数相等时随机）。
  - 正在匹配队列中时，页面左下角出现"取消匹配"按钮，点击即退出当前队列（效果与 `/cstmm match leave` 相同）。
- **队列页**：实时展示匹配状态（服务端有变化时自动推送，无需刷新）——自己的排队地图与模式、已匹配/还差人数；自己战队的排队情况；每张地图的可匹配状态（对局中 / 被禁用 / 冷却中 / 可用 + 蓝红两队人数），每 3 秒在竞技/休闲人数之间轮换展示（地图行右下角有 `[竞技]` / `[休闲]` 标识）。
- **战队页**：
  - **未加入战队**：左侧展示选中战队的详情（名称 / 缩写 / 徽标 / 队长 / 人数上限），右侧为战队列表（随机展示 10 条，支持按名称 / 缩写 / 队长搜索）；底部可搜索或创建战队（创建需填写名称、缩写、徽标（base64 可留空，留空为黑色方块）、成员上限（0 = 无限制））。
  - **已加入战队**：顶部显示战队信息；中部为成员列表（`[队长]` 标注；在线名字绿色、离线灰色；匹配状态显示 离线 / 空闲 / 正在匹配的地图-模式）；底部按钮——退出战队（所有人）、解散战队与编辑战队信息（仅队长，编辑可修改全部四项信息）。
  - 战队只影响匹配分队偏好（同战队尽量分到同一队、不同战队尽量不同队），不影响战绩、击杀等其他任何功能。
- **履历页**：查看个人战绩（击杀 / 死亡 / 胜率）。
- **关于页**：模组信息与"模组仓库 / 报告问题"快捷链接（旁边的"千万别点"按钮是个彩蛋，后果自负）。
- 右下角显示模组版本号。

## 商店（默认 ' 键（L键右边的右边））

- 打开商店自动加载当前地图的商品列表。
- **仅竞技模式对局中的玩家可购买**；休闲模式或对局外无法购买。
- 商品价格与限购次数由地图配置决定。

---

## 对局 HUD

对局期间屏幕中央上方显示半透明信息板：地图名、红/蓝队击杀数、剩余时间、击杀占比条。对局结束或断线自动消失。

---

## 竞技模式 vs 休闲模式

模式由**加入队列时**的选择决定，与地图无关：

| 行为 | 竞技模式 | 休闲模式 |
|---|---|---|
| 开局背包 | 保存并清空 | 不动背包 |
| 默认装备 | 发放 | 不发放 |
| 商店 | 可用 | 不可用 |
| 友伤 | 启用（可伤害队友） | 禁用 |
| 结束后 | 恢复背包 + 传送回原位置 | 传送回原位置 |

> 观战者造成的击杀不记录、不播报。

## 常用命令

| 命令 | 说明 |
|---|---|
| `/cstmm match leave` | 离开匹配队列 |
| `/cstmm match status` | 查看自己的队列/对局状态 |
| `/cstmm match status_quick` | 查看快速匹配队列人数 |
| `/cstmm match list` | 列出进行中的对局 |
| `/cstmm vote kick <玩家>` | 发起踢人投票 |
| `/cstmm vote kickyes / kickno` | 投票（同 F7/F8） |

## 对局规则速览

- **开局条件**：红蓝两队人数分别达到该图最低人数要求；同一地图竞技/休闲队列先到先得开局。
- **快速匹配**：匹配不到人时会与同模式队列合并，超时后加入正在进行中的同模式对局（补位）。
- **越界处罚**：离开地图边界会收到警告，超时未返回会被处决，对方队伍获得惩罚击杀。
- **死亡重生**：对局未结束时自动传回本队出生点。
- **胜负**：先达到击杀目标（KILLS）或时限结束时击杀多者获胜（TIMER）；平局可能发起加时投票。

## 常见问题

| 现象 | 处理 |
|---|---|
| 进服提示"未与服务端握手成功" | 服务端未装模组或两端版本不一致，请联系管理员获取帮助 |
| 匹配一直不开局 | 人数未达到该图最低要求，或该图正在对局/冷却中 |
| 商店显示"无法购买" | 仅竞技模式对局内可购买 |
| 对局中背包异常 | 竞技模式结束会自动恢复背包；异常时联系管理员执行 `/cstmm data restore bags` |
