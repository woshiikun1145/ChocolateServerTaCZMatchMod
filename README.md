# Chocolate Server TaCZ Match Mod（CSTMM）

> 玩家手册 + 模组说明

为 Chocolate Server 的 TaCZ 子服设计的 **匹配对战 / 商店 / 投票** 模组。玩家查阅下方[玩家手册](#第一部分玩家手册)；服务器管理员与开发者请参阅[模组说明](#第二部分模组说明)与文末的[文档索引](#文档索引)。

***

# 第一部分：玩家手册

## 一、默认快捷键

| 默认快捷键 | 功能                |
| ----- | ----------------- |
| `;`   | 打开/关闭匹配菜单（L 键右边）  |
| `'`   | 打开/关闭商店（L 键右边的右边） |
| `F7`  | 投票：同意             |
| `F8`  | 投票：不同意            |

> 未与服务端握手成功时所有快捷键不可用，如果你已确认你的模组没有问题，请联系服务器管理员处理。

## 二、一分钟开局

1. 按 `;` 打开匹配菜单，进入 **匹配** 标签页。
2. 标题栏右侧选择 **休闲模式 / 竞技模式**（选中的带 `✔`）。
3. 点击地图卡片加入队列（或点首张"⚡ 快速匹配"卡片由系统选图）。
4. 人数达标自动开局、自动分队，屏幕上方出现对局 HUD。
5. 排队期间可点左下角 **取消匹配** 按钮或 `/cstmm queue leave` 退出队列。

## 三、匹配菜单详解（`;` 键）

### 3.1 欢迎页

模组介绍与当前可用地图数量。

### 3.2 匹配页

- 标题栏右侧选择 **休闲模式 / 竞技模式**，加入队列时按当前选中的模式入队。
- 卡片列表：每张启用的地图一张卡片，首张为"⚡ 快速匹配"入口。
- 点击卡片直接加入队列（快速匹配无队伍概念）。**队伍在人数满足开局条件、准备开局时才由系统自动分配**（两队均衡，同战队尽量同队）——排队期间没有红蓝之分。
- 正在队列中时，页面左下角出现 **取消匹配** 按钮，点击即退出当前队列（效果与 `/cstmm queue leave` 相同）。

### 3.3 队列页

实时展示匹配状态（服务端有变化时自动推送，无需刷新）：

- 自己的排队地图与模式、已匹配 / 还差人数（自己的头像显示在战队徽标右侧）；
- 自己战队的排队情况；
- 每张地图的可匹配状态（对局中 / 被禁用 / 冷却中 / 可用 + 该模式排队人数），每 3 秒在竞技 / 休闲之间轮换展示（地图行右下角有 `[竞技]` / `[休闲]` 标识）。

### 3.4 战队页

- **未加入战队**：左侧展示选中战队的详情（名称 / 缩写 / 徽标 / 队长 / 人数上限），右侧为战队列表（随机展示 10 条，支持按名称 / 缩写 / 队长搜索）；底部可搜索或创建战队（创建需填写名称、缩写、徽标（base64，可留空，留空为黑色方块）、成员上限（0 = 无限制））。
- **已加入战队**：顶部显示战队信息；中部为成员列表（`[队长]` 标注；头像显示在名字左侧；在线名字绿色、离线灰色；匹配状态显示 离线 / 空闲 / 正在匹配：地图-模式——"正在匹配"以主题色高亮）；底部按钮——退出战队（所有人）、解散战队与编辑战队信息（仅队长，编辑可修改全部四项信息）。
- 战队只影响匹配分队偏好（同战队尽量同队、不同战队尽量分队），不影响战绩、击杀等其他任何功能。

### 3.5 履历页

- **上方为"我的履历"**：头像 + 自己的击杀 / 死亡 / K/D / 场次 / 胜场 / 胜率。
- **下方为"全服履历"排行**：每位玩家的排名 / 名字 / 击杀 / 死亡 / K/D / 场次 / 胜率，人数多时可滚动查看；自己的行以主题色高亮，前三名有金银铜配色。
- **排序**：右上角下拉菜单可按 **K/D、胜率、总击杀** 三种方式排序，切换即时生效。
- 每次进入履历页自动刷新为最新数据。

### 3.6 个性化页

- **界面主题色**：8 个预设色板或自定义 HEX，点击即时生效并本地保存（影响标题、侧边栏标记、弹窗边框等）。
- **头像绑定**：选择 QQ / 哔哩哔哩平台并输入自己的账号 ID（纯数字），预览确认后保存到服务器；头像显示在战队成员列表、队列页与履历页。仅上报平台与账号 ID，头像图片由每个玩家自己的客户端获取。

### 3.7 关于页

模组信息与"模组仓库 / 报告问题"快捷链接（旁边的"千万别点"按钮是个彩蛋，后果自负）。

> 菜单右下角显示模组版本号。

## 四、玩法系统

### 4.1 竞技模式 vs 休闲模式

模式由**加入队列时**的选择决定，与地图无关：

| 行为   | 竞技模式          | 休闲模式   |
| ---- | ------------- | ------ |
| 开局背包 | 保存并清空         | 不动背包   |
| 默认装备 | 发放            | 不发放    |
| 商店   | 可用            | 不可用    |
| 友伤   | 启用（可伤害队友）     | 禁用     |
| 结束后  | 恢复背包 + 传送回原位置 | 传送回原位置 |

### 4.2 对局规则

- **开局条件**：某地图队列总人数达到该图两队最低人数之和即开局，**开局时才自动分配队伍**（战队尽量同队、两队均衡）；同一地图竞技 / 休闲队列先到先得开局。
- **快速匹配**：匹配不到人时会与同模式队列合并，超时后加入正在进行中的同模式对局（补位）。
- **越界处罚**：离开地图边界会收到警告，超时未返回会被处决，对方队伍获得惩罚击杀。
- **死亡重生**：对局未结束时自动传回本队出生点。
- **胜负**：先达到击杀目标（KILLS）或时限结束时击杀多者获胜（TIMER）；平局可能发起加时投票。

### 4.3 对局 HUD（CS2 风格队伍栏）

对局期间屏幕顶部显示 CS2 风格三段式队伍栏：**己方队伍卡片在左、敌方在右、中央计分板**。

- **玩家卡片**：队色边框头像（绑定过的 QQ/B站头像自动显示，右下角叠加战队徽标）+ 名字条 `[战队缩写][队伍]玩家名`；自己的卡片金色描边。
- **卡片下挂当局统计**：准备阶段与对局期间均显示 `N杀 K/D X.X`（存活白色、阵亡置灰）；准备阶段另有头像左下角血量数字与上一条命击杀徽章（绿色 N杀），对局期间存活玩家显示红色血条、阵亡玩家头像变暗并显示白色小骷髅。
- **中央计分板**：地图名、倒计时（>60 秒白色 → ≤60 秒金色 → ≤30 秒红色）、红蓝比分（领先方亮队色、落后方暗队色、平局双方亮色）、双方存活人数。
- **爆破对局 HUD 变化**：比分行显示回合比分（`T x : y CT`）；C4 安放后倒计时切换为红色爆炸倒计时；计分板下方状态行按优先级显示 `C4 已安放`（红，不提示包点位置，CT 需自行寻找）→ `炸弹正在被拆除！`（蓝）→ `对方全队离线，等待重连`（黄）→ `购买窗口开启`（绿）。
- **拆弹器标记**：爆破对局中持有拆弹装备的 CT 玩家，卡片右上角显示绿色小钳图标。

对局结束或断线自动消失。

> 管理员调试：`/cstmm debug match_info_hud t` 可强制显示信息栏（仅执行命令的管理员自己的客户端会看到首个活跃对局的信息栏；无对局时显示"HUD 调试预览"计分板），`f` 关闭复位。仅限游戏内玩家执行。

### 4.4 商店（`'` 键）

- 打开商店加载当前地图的商品，购买页为 **5 列一页式网格**（列内商品超出可滚轮上下滚动；每格显示图标/名称/价格）。
- **普通竞技图**：仅竞技模式对局中可购买，免费发放；价格与限购次数仅作展示，5 列分类由配置统一设定。
- **爆破图（BOMB）**：休闲/竞技对局中均可购买，走**经济系统**——价格 = 匹配内货币（非服务器货币，对局结束清零）：
  - 购买页 **1+4 列**：第 1 列固定"装备"列（**仅 CT** 显示拆弹装备购买项，T 方为空列），第 2~5 列为分类列（**T 方与 CT 方各自独立配置**，未单独配置时两队伍共用一套）。
  - 购买窗口：冻结时间 + 开局后 20 秒（全局可配）；炸弹安放后禁买。
  - 余额不足或窗口关闭的商品置灰不可点；购买成功即时刷新余额。
  - 金额规则（CS 标准，全局可配）：起始 $800 / 上限 $16000 / 击杀 $300（休闲减半）/ 胜利金 3250（全歼·超时）· 3500（爆炸·拆除）/ 败金 1400 起连败 +500 封顶 3400 / 安放·拆除个人 $300；半场与加时重置金额。
- `cstmm:bomb_defuser`（拆弹装备条目）仅 CT 可购买，购买后获得持有状态（玩家 tag，非背包物品）；`cstmm:c4` 由系统回合开始指派，无法购买。

### 4.5 爆破模式（gameType=BOMB 的地图）

复刻 CS 爆破玩法：红蓝两队改为 **T（进攻）/CT（防守）**，多回合赛制。

- **回合流程**：回合开始全员复活/回出生点（阵亡者回默认装备、存活者保留装备）→ 冻结阶段（可购买）→ 战斗阶段。
- **C4**：回合开始随机指派一名 T 携带 `cstmm:c4`；进入包点（**立方体判定**：以包点中心为基准，三轴距离均不超过配置半径）后手持 C4 **长按右键**安放（默认 3 秒）；安放后生成 C4 实体，倒计时归零先播引信音、播完才爆炸（伤害按文档模型结算：距离衰减 + 墙体遮挡 + 开口穿透 + 背对减伤，双方都受伤害）。
- **拆除**：CT 在 C4 附近**长按使用键（右键）**拆除，带拆弹装备 5 秒 / 裸拆 10 秒；拆弹装备**不是物品**（持有状态为玩家 tag，HUD 卡片右上角绿色小钳标记）：休闲模式每个 CT 回合自动获得，竞技模式阵亡丢失、商店可购（$400 类商品条目 `cstmm:bomb_defuser`，购买即获得），对局结束自动回收。
- **胜负**：全歼 / 超时（未安放 CT 胜）/ 爆炸（T 胜）/ 拆除（CT 胜）。安放后 T 全灭不结束回合（CS 规则）。
- **赛制**：休闲先到 8 分获胜；竞技 MR12（先到 13 胜，12:12 进加时 BO6 先到 4 胜，加时 3:3 全队投票继续或平局结束）；竞技第 13 回合、加时第 4 回合攻防转换，经济随之重置。
- **死亡**：死后变旁观者直到回合结束；断线有 3 分钟重连宽限（回合结束清算超时；整队离线挂起等待重连）。

### 4.6 投票

- **踢人投票**：`/cstmm vote kick <玩家>` 发起，`F7` 同意 / `F8` 反对（等价于 `/cstmm vote kickyes / kickno`）。
- **加时投票**：时限平局时可能由系统发起，同样用 `F7` / `F8` 表决。

## 五、常用命令

| 命令                             | 说明                                    |
| ------------------------------ | ------------------------------------- |
| `/cstmm queue join <地图> [模式]`  | 加入地图匹配队列（模式: COMPETITIVE/CASUAL，默认竞技） |
| `/cstmm queue quick [模式]`      | 加入快速匹配队列                              |
| `/cstmm queue leave`           | 离开匹配队列                                |
| `/cstmm queue status`          | 查看队列状态与快速匹配人数                         |
| `/cstmm match status`          | 查看自己的对局状态                             |
| `/cstmm match list`            | 列出进行中的对局                              |
| `/cstmm vote kick <玩家>`        | 发起踢人投票                                |
| `/cstmm vote kickyes / kickno` | 投票（同 F7/F8）                           |
| `/cstmm data edit map <地图> gametype <NORMAL\|BOMB>` | 设置地图类型（爆破图/普通图，管理员） |
| `/cstmm data edit map <地图> bombsites add <名> <x> <y> <z> [半径]` | 添加包点（半径=立方体半边长；remove <名\|序号> / clear 删除，管理员） |

> 管理员 / 调试命令见 [DEVELOPER.md](DEVELOPER.md) §7。

## 六、常见问题

| 现象              | 处理                                                  |
| --------------- | --------------------------------------------------- |
| 进服提示"未与服务端握手成功" | 服务端未装模组或两端版本不一致，请联系管理员                              |
| 匹配一直不开局         | 人数未达到该图最低要求，或该图正在对局 / 冷却中                           |
| 商店显示"无法购买"      | 仅竞技模式对局内可购买                                         |
| 对局中背包异常         | 竞技模式结束会自动恢复背包；异常时联系管理员执行 `/cstmm data restore bags` |
| 战队徽标不显示         | 徽标按内容缓存，本地缺失时会自动请求补发，稍等片刻即可                         |

# 第二部分：模组说明

## 七、这是什么

CSTMM 是一个 **服务端 + 客户端双端** Fabric 模组，为 TaCZ 枪械服提供完整的竞技对战循环：

- **匹配系统**：按地图排队，支持 **竞技 / 休闲** 两种模式与"快速匹配"入口；人数达标自动开局、自动分队，满员对局支持补位加入。
- **战队系统**：创建 / 加入 / 管理战队（自定义徽标），匹配分队时同战队尽量同队、不同战队尽量分队。
- **商店系统**：竞技对局内按地图配置购买商品；爆破图走独立经济系统（CS 标准金额规则，全局可配）。
- **爆破模式**：gameType=BOMB 的地图启用 CS 式爆破玩法——多回合赛制（休闲先到 8 分 / 竞技 MR12+加时）、T/CT 攻防、C4 安放拆除交互、CS 标准经济与购买窗口、3 分钟断线重连宽限。
- **投票系统**：踢人投票（F7/F8）、平局加时投票。
- **对局引擎**：记分、HUD 实时播报、地图边界检测与越界处罚、死亡重生回出生点、击杀目标 / 时限两种结算方式。
- **战绩履历**：记录击杀 / 死亡 / 胜率；履历页可查看自己战绩与全服排行（按 K/D / 胜率 / 总击杀排序）。
- **个性化**：自定义界面主题色；绑定自己 QQ / B站账号头像（仅存平台与账号 ID，图片由各客户端自行获取），显示在战队成员列表、队列页与履历页。
- **OP 配置界面**：管理员游戏内可视化配置地图、商店与全局参数（配置实时同步全服）。

## 八、运行要求

| 项目            | 要求                                         |
| ------------- | ------------------------------------------ |
| Minecraft     | 1.21.1                                     |
| Fabric Loader | 0.16.0+                                    |
| Fabric API    | 0.115.6+1.21.1                             |
| 部署形态          | **服务端与客户端必须安装同版本模组**（进服自动握手校验，版本不一致功能全部禁用） |
| 许可证           | MIT                                        |

## 九、安装

1. 服务端：将模组 jar 放入服务器 `mods/` 目录，重启服务器。首次启动生成 `config/cstmm/` 配置目录。
2. 客户端：将**同版本** jar 放入客户端 `mods/` 目录（需 Fabric API）。
3. 进服后聊天栏出现握手成功提示即安装正确；提示"未与服务端握手成功"时见[常见问题](#六常见问题)。
