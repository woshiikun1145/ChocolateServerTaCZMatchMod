# Chocolate Server Tacz Match Mod（CSTMM）

> 玩家手册 + 模组说明

为 Chocolate Server 的 TaCZ 子服设计的 **匹配对战 / 商店 / 投票** 模组。玩家在本手册查阅玩法与操作；服务器管理员与开发者请参阅文末的[文档索引](#文档索引)。

---

## 一、模组说明

### 1.1 这是什么

CSTMM 是一个 **服务端 + 客户端双端** Fabric 模组，为 TaCZ 枪械服提供完整的竞技对战循环：

- **匹配系统**：按地图排队，支持 **竞技 / 休闲** 两种模式与"快速匹配"入口；人数达标自动开局、自动分队，满员对局支持补位加入。
- **战队系统**：创建 / 加入 / 管理战队（自定义徽标），匹配分队时同战队尽量同队、不同战队尽量分队。
- **商店系统**：竞技对局内按地图配置购买商品。
- **投票系统**：踢人投票（F7/F8）、平局加时投票。
- **对局引擎**：记分、HUD 实时播报、地图边界检测与越界处罚、死亡重生回出生点、击杀目标 / 时限两种结算方式。
- **战绩履历**：记录击杀 / 死亡 / 胜率，菜单内查看。
- **个性化**：自定义界面主题色；绑定自己 QQ / B站账号头像（仅存平台与账号 ID，图片由各客户端自行获取），显示在战队成员列表、队列页与履历页。
- **OP 配置界面**：管理员游戏内可视化配置地图、商店与全局参数（配置实时同步全服）。

### 1.2 运行要求

| 项目 | 要求 |
|---|---|
| Minecraft | 1.21.1 |
| Fabric Loader | 0.16.0+ |
| Fabric API | 0.115.6+1.21.1 |
| 部署形态 | **服务端与客户端必须安装同版本模组**（进服自动握手校验，版本不一致功能全部禁用） |
| 许可证 | MIT |

### 1.3 安装

1. 服务端：将模组 jar 放入服务器 `mods/` 目录，重启服务器。首次启动生成 `config/cstmm/` 配置目录。
2. 客户端：将**同版本** jar 放入客户端 `mods/` 目录（需 Fabric API）。
3. 进服后聊天栏出现握手成功提示即安装正确；提示"未与服务端握手成功"时见[常见问题](#六常见问题)。

## 二、快速上手

### 2.1 快捷键

| 快捷键 | 功能 |
|---|---|
| `;` | 打开/关闭匹配菜单（L 键右边） |
| `'` | 打开/关闭商店（L 键右边的右边） |
| `F7` | 投票：同意 |
| `F8` | 投票：不同意 |

> 未与服务端握手成功时所有快捷键不可用，请联系服务器管理员。

### 2.2 一分钟开局

1. 按 `;` 打开匹配菜单，进入 **匹配** 标签页。
2. 标题栏右侧选择 **休闲模式 / 竞技模式**（选中的带 `✔`）。
3. 点击地图卡片加入队列（或点首张"⚡ 快速匹配"卡片由系统选图）。
4. 人数达标自动开局、自动分队，屏幕上方出现对局 HUD。
5. 排队期间可点左下角 **取消匹配** 按钮或 `/cstmm queue leave` 退出队列。

## 三、匹配菜单详解（`;` 键）

### 3.1 欢迎页

模组介绍与当前可用地图数量。

### 3.2 匹配页

- 标题栏右侧选择 **休闲模式 / 竞技模式**，加入队列时按当前选中的模式入队。
- 卡片列表：每张启用的地图一张卡片，首张为"⚡ 快速匹配"入口。
- 点击卡片直接加入队列（快速匹配无队伍概念）。**队伍在人数满足开局条件、准备开局时才由系统自动分配**（两队均衡，同战队尽量同队）——排队期间没有红蓝之分。
- 正在队列中时，页面左下角出现 **取消匹配** 按钮，点击即退出当前队列（效果与 `/cstmm queue leave` 相同）。

### 3.3 队列页

实时展示匹配状态（服务端有变化时自动推送，无需刷新）：

- 自己的排队地图与模式、已匹配 / 还差人数（自己的头像显示在战队徽标右侧）；
- 自己战队的排队情况；
- 每张地图的可匹配状态（对局中 / 被禁用 / 冷却中 / 可用 + 该模式排队人数），每 3 秒在竞技 / 休闲之间轮换展示（地图行右下角有 `[竞技]` / `[休闲]` 标识）。

### 3.4 战队页

- **未加入战队**：左侧展示选中战队的详情（名称 / 缩写 / 徽标 / 队长 / 人数上限），右侧为战队列表（随机展示 10 条，支持按名称 / 缩写 / 队长搜索）；底部可搜索或创建战队（创建需填写名称、缩写、徽标（base64，可留空，留空为黑色方块）、成员上限（0 = 无限制））。
- **已加入战队**：顶部显示战队信息；中部为成员列表（`[队长]` 标注；头像显示在名字左侧；在线名字绿色、离线灰色；匹配状态显示 离线 / 空闲 / 正在匹配：地图-模式——"正在匹配"以主题色高亮）；底部按钮——退出战队（所有人）、解散战队与编辑战队信息（仅队长，编辑可修改全部四项信息）。
- 战队只影响匹配分队偏好（同战队尽量同队、不同战队尽量分队），不影响战绩、击杀等其他任何功能。

### 3.5 履历页

查看个人战绩（击杀 / 死亡 / 胜率），自己的头像显示在资料左侧。

### 3.6 个性化页

- **界面主题色**：8 个预设色板或自定义 HEX，点击即时生效并本地保存（影响标题、侧边栏标记、弹窗边框等）。
- **头像绑定**：选择 QQ / 哔哩哔哩平台并输入自己的账号 ID（纯数字），预览确认后保存到服务器；头像显示在战队成员列表、队列页与履历页。仅上报平台与账号 ID，头像图片由每个玩家自己的客户端获取。

### 3.7 关于页

模组信息与"模组仓库 / 报告问题"快捷链接（旁边的"千万别点"按钮是个彩蛋，后果自负）。

> 菜单右下角显示模组版本号。

## 四、玩法系统

### 4.1 竞技模式 vs 休闲模式

模式由**加入队列时**的选择决定，与地图无关：

| 行为 | 竞技模式 | 休闲模式 |
|---|---|---|
| 开局背包 | 保存并清空 | 不动背包 |
| 默认装备 | 发放 | 不发放 |
| 商店 | 可用 | 不可用 |
| 友伤 | 启用（可伤害队友） | 禁用 |
| 结束后 | 恢复背包 + 传送回原位置 | 传送回原位置 |

### 4.2 对局规则

- **开局条件**：某地图队列总人数达到该图两队最低人数之和即开局，**开局时才自动分配队伍**（战队尽量同队、两队均衡）；同一地图竞技 / 休闲队列先到先得开局。
- **快速匹配**：匹配不到人时会与同模式队列合并，超时后加入正在进行中的同模式对局（补位）。
- **越界处罚**：离开地图边界会收到警告，超时未返回会被处决，对方队伍获得惩罚击杀。
- **死亡重生**：对局未结束时自动传回本队出生点。
- **胜负**：先达到击杀目标（KILLS）或时限结束时击杀多者获胜（TIMER）；平局可能发起加时投票。

### 4.3 对局 HUD

对局期间屏幕中央上方显示半透明信息板：地图名、红 / 蓝队击杀数、剩余时间、击杀占比条。对局结束或断线自动消失。

### 4.4 商店（`'` 键）

- 打开商店自动加载当前地图的商品列表。
- **仅竞技模式对局中的玩家可购买**；休闲模式或对局外无法购买。
- 商品价格与限购次数由地图配置决定。

### 4.5 投票

- **踢人投票**：`/cstmm vote kick <玩家>` 发起，`F7` 同意 / `F8` 反对（等价于 `/cstmm vote kickyes / kickno`）。
- **加时投票**：时限平局时可能由系统发起，同样用 `F7` / `F8` 表决。

## 五、常用命令

| 命令 | 说明 |
|---|---|
| `/cstmm queue join <地图> [模式]` | 加入地图匹配队列（模式: COMPETITIVE/CASUAL，默认竞技） |
| `/cstmm queue quick [模式]` | 加入快速匹配队列 |
| `/cstmm queue leave` | 离开匹配队列 |
| `/cstmm queue status` | 查看队列状态与快速匹配人数 |
| `/cstmm match status` | 查看自己的对局状态 |
| `/cstmm match list` | 列出进行中的对局 |
| `/cstmm vote kick <玩家>` | 发起踢人投票 |
| `/cstmm vote kickyes / kickno` | 投票（同 F7/F8） |

> 管理员 / 调试命令见 [DEVELOPER.md](DEVELOPER.md) §7。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 进服提示"未与服务端握手成功" | 服务端未装模组或两端版本不一致，请联系管理员 |
| 匹配一直不开局 | 人数未达到该图最低要求，或该图正在对局 / 冷却中 |
| 商店显示"无法购买" | 仅竞技模式对局内可购买 |
| 对局中背包异常 | 竞技模式结束会自动恢复背包；异常时联系管理员执行 `/cstmm data restore bags` |
| 战队徽标不显示 | 徽标按内容缓存，本地缺失时会自动请求补发，稍等片刻即可 |
